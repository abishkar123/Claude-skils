# Planning Workflows

## Weekly Planning

Goal: produce a realistic plan that balances commitments, priorities, energy, recovery, and professional growth.

Inputs to request:
- Fixed commitments: meetings, appointments, deadlines, family obligations.
- Flexible tasks: work, admin, errands, learning, personal projects.
- Goals: professional outcomes, personal goals, habits, skill-building.
- Constraints: energy, travel, health, caregiving, budget, focus limits.
- Previous-week signal: wins, misses, unfinished work, lessons.

Procedure:
1. Capture commitments in one list. Separate fixed-time commitments from flexible work.
2. Review the previous week with three questions: What moved forward? What slipped? What should change?
3. Identify 3-5 weekly priorities. Label each as must, should, or could.
4. Estimate capacity. Count realistic focus blocks, admin blocks, recovery blocks, and commute/context-switch costs.
5. Create the plan. Put fixed commitments first, then priority work, then admin, then optional items.
6. Flag overloaded days. A day is overloaded when planned work exceeds available blocks, contains more than one high-cognitive-load priority, lacks recovery after intense commitments, or depends on perfect execution.
7. Define success criteria. Use observable outcomes, not intentions.
8. Add fallback rules: minimum viable week, items to defer, and decision points.

Output format:
- Week theme
- Top priorities
- Capacity snapshot
- Day-by-day plan
- Overload flags
- Tradeoffs and deferrals
- Success criteria
- Review prompts

## Weekend Planning

Goal: restore energy while making personal life feel handled.

Required categories:
- Recovery and rest
- Errands and admin
- Learning block
- Relationship/social time
- Personal projects
- Monday preparation

Procedure:
1. Ask what kind of weekend is needed: restorative, productive, social, mixed, or catch-up.
2. Protect sleep, meals, movement, and open space before adding tasks.
3. Pick one primary weekend outcome and one secondary outcome.
4. Timebox errands/admin. Batch by location or tool.
5. Schedule one learning block only if it has a clear scope.
6. Include relationship/social time deliberately, including low-effort options.
7. Reserve Monday preparation: calendar scan, task triage, clothes/food/workspace setup, first work block.
8. Keep at least one unscheduled buffer block.

## Daily Execution

Goal: convert today into a small number of completed outcomes.

Morning plan:
- Confirm fixed calendar items.
- Select Top 3 outcomes.
- Match tasks to energy windows.
- Reserve one deep work block where possible.
- Decide what will not be done today.

Distraction handling:
- Define a capture place for interruptions.
- Use a "not now" list for impulses.
- Set communication windows.
- Pre-plan recovery after meetings or intense work.

End-of-day review:
- Completed
- Carried forward
- Blocked
- Energy pattern
- One improvement for tomorrow

## Professional Growth

Use this workflow when the user asks about career goals, promotion, visibility, project impact, communication, resumes, LinkedIn, performance reviews, or professional development.

Career goal framing:
- Target role or next level
- Required capabilities
- Current strengths
- Gaps
- Evidence needed
- Timeline

Promotion-readiness assessment:
Score each 1-5:
- Scope: work affects a meaningful audience or system.
- Autonomy: user drives work with appropriate independence.
- Impact: outcomes are measurable.
- Leadership: user improves others' work or decisions.
- Communication: updates are clear, timely, and audience-aware.
- Reliability: commitments are met or renegotiated early.

Evidence log fields:
- Date
- Project or initiative
- Problem
- Action taken
- Result
- Metric or signal
- Stakeholders
- Skill demonstrated
- Artifact link or source
- Resume/LinkedIn bullet draft

Communication coaching:
- Convert work into audience-specific updates.
- Use situation, action, impact, ask.
- Make risks visible early.
- Include decisions needed and deadlines.
- Save strong updates as evidence.

Resume/LinkedIn capture:
- Use action verb + scope + measurable result.
- Prefer concrete systems, users, revenue, cost, quality, speed, reliability, or team outcomes.
- If metrics are unavailable, capture credible proxies such as adoption, stakeholder feedback, risk reduction, cycle time, or before/after complexity.
