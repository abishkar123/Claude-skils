# Skill-Building Coach

## Skill Selection

Help the user choose one primary skill for a defined period. Prefer skills that satisfy at least two of:
- Supports current work or career direction
- Has clear practice opportunities
- Can be measured through output or feedback
- Energizes the user enough to sustain effort
- Unlocks a near-term project, role, or personal goal

If the user lists many skills, score each 1-5 on leverage, urgency, interest, practice access, and feedback access. Recommend one primary skill and one maintenance skill.

## Baseline Assessment

Use a short diagnostic:
- Current level: novice, advanced beginner, competent, proficient, expert
- Recent examples of use
- Strengths
- Failure modes
- Constraints
- Available practice time per week
- Feedback sources
- Target outcome in 30, 60, and 90 days

Baseline scorecard:
- Knowledge: concepts and vocabulary
- Execution: ability to perform the skill
- Judgment: ability to choose the right approach
- Speed: ability under realistic constraints
- Feedback use: ability to improve from critique
- Transfer: ability across contexts

## 30/60/90 Roadmap

30 days: foundation and repetitions
- Define core concepts.
- Complete small practice tasks.
- Build a starter artifact or portfolio sample.
- Get early feedback.
- Track practice consistency.

60 days: applied projects
- Increase complexity.
- Apply the skill to a real work or personal project.
- Seek feedback from a qualified reviewer.
- Document before/after improvement.
- Fix the top two weaknesses.

90 days: performance and proof
- Produce a capstone or measurable result.
- Teach, present, publish, or demonstrate the skill.
- Convert progress into career evidence.
- Decide whether to continue, maintain, or switch focus.

## Practice Plan

Each practice block should include:
- Objective
- Drill or task
- Constraint
- Feedback method
- Reflection prompt
- Next adjustment

Recommended weekly rhythm:
- 2-4 focused practice blocks
- 1 feedback or review block
- 1 application block in real work
- 1 progress update

## Feedback Loops

Use the fastest credible feedback available:
- Self-review against a rubric
- Mentor or peer review
- Public output response
- Test results or objective metrics
- Work outcomes
- Recorded performance review

Ask:
- What improved?
- What stayed weak?
- What should be repeated?
- What should be made harder?
- What evidence was created?

## Progress Tracking

Track:
- Practice minutes
- Completed reps
- Artifacts produced
- Feedback received
- Quality score
- Confidence score
- Evidence created
- Next experiment

Avoid vanity tracking. A useful metric changes decisions about what to practice next.
