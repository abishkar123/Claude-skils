# Workflow: Personal Review (Daily / Weekly / Monthly / Quarterly)

**Owner:** Review Agent · **Supports:** all specialists, Database Memory, QA

## Example Requests
- "End-of-day review." · "Run my weekly review." · "Monthly review for May."
- "Quarterly review — and tell me if my goals still make sense."

## Common Mechanics (all cadences)
- Works from: stored records (if DB approved) > pasted notes/ledger blocks >
  guided recall questions (marked recall-based in Assumptions).
- Every review ends with: **next actions (owner + date)** and **follow-up
  commitments** that are explicitly checked at the next review of that cadence.
- Misses get one of four causes: overcommitted / interrupted / underestimated /
  avoided. Patterns (same cause 3×) get structural fixes, not "try harder."
- Wins are screened for promotion-worthy evidence → offer Professional Growth
  handoff.

## Daily (3–5 min)
Done vs. planned top-3 · one win · one friction · carry-over decisions
(tomorrow / reschedule / drop) · energy 1–5 · habit ticks.

## Weekly (15–20 min)
1. Plan vs. actual per must-do (completion rate).
2. Wins (≥3, small counts) · misses with causes.
3. Blockers: still active? Who/what unblocks?
4. Habit adherence x/y per habit; friction note on any <50%.
5. Evidence capture prompt (3 questions → Professional Growth).
6. Lessons → 1–3 process changes for next week (these are the follow-up
   commitments checked next week).
7. Feed-forward: output summarized into next Weekly Planning run.

## Monthly (30–45 min)
1. Roll up weekly reviews; completion + habit trends (direction, not guilt).
2. **Pattern detection:** recurring causes, recurring blockers, energy
   patterns by day/week.
3. Goal progress: on/off track per goal + why; goal CHANGES are legitimate
   outputs (rescope, defer, drop — recorded with reason).
4. Skill roadmap checkpoint (sync with day-30/60/90 probes when aligned).
5. Start / stop / continue (max 2 each).
6. Next month's 3 priorities + follow-up commitments.

## Quarterly (60–90 min)
1. Goal-level retrospective: planned vs. achieved per quarterly goal.
2. Career checkpoint with Professional Growth Agent: readiness delta since
   last quarter, evidence log health.
3. Skill 90-day probe results vs. target capability; next skill decision.
4. Habit system review: which habits are now automatic, which need redesign.
5. **System review:** is this productivity OS itself working? What to change
   in the templates/cadence?
6. Next quarter: max 3 goals, each with success criteria and a monthly
   checkpoint.

## Manual Fallback
Each cadence has a question script (above) runnable from pure recall. Missing
history is stated, never fabricated.

## Storage
`reviews` collection with `cadence` field; habit ticks in `habits`. Without DB:
ledger blocks per review, pasteable into the next session.
