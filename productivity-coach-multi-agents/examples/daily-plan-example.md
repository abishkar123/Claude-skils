# Example: Daily Execution Plan (Manual Mode)

> **User request:** "Plan my Tuesday. Meetings 10–10:30 standup, 2–3 design
> review. Must finish migration tests. Also owe Sam a doc review and have ~20
> small queued tasks. Morning person."

## Daily Plan: Tuesday Jun 16

**Objective:** Migration tests finished and green, with Sam unblocked, despite a split-up afternoon.

**Inputs used:** Manual: 2 meetings, 1 primary deliverable, 1 owed review, queued small tasks, morning-peak energy.

**Assumptions:** Workday 9–5:30. Migration tests ≈ 3h (inflated from "should be quick"). Doc review 30 min. The 20 queued tasks are NOT today's job — 30 min batch max.

**Top 3:** 1) Migration tests written + passing 2) Sam's doc review sent 3) Design-review prep (15 min skim)
**Minimum viable day:** migration tests passing. Everything else can move.

| Time | Block |
|------|-------|
| 9:00–10:00 | **Deep work #1** — migration tests (notifications off) |
| 10:00–10:30 | Standup |
| 10:30–12:30 | **Deep work #2** — migration tests, finish + run |
| 12:30–1:15 | Lunch, away from desk |
| 1:15–1:45 | Sam's doc review → send |
| 1:45–2:00 | Design-review skim |
| 2:00–3:00 | Design review |
| 3:00–3:30 | Small-task batch (top of queue only) |
| 3:30–5:00 | Buffer: spillover, replies, parking lot |
| 5:00–5:05 | End-of-day review |

**Parking lot:** capture intrusions here, process at 3:30.
**If interrupted during deep work:** write a one-line "I was about to ___" restart note, handle it, return.

### Capacity Check
Meetings 1.5h · planned 5.25h · buffer 1.5h on a usable ~6h (0.7×8.5) — 88% with buffer counted in. Tight but honest; the small-task queue is the relief valve.

### Risks & Overload Warnings
- ⚠ If tests aren't passing by 12:30, the 3:00 small-task batch becomes test time. Decide at lunch, not at 4pm.

### Tradeoffs
19 of 20 queued tasks wait. The queue is a backlog, not a to-do list.

### Success Criteria
Tests green · Sam unblocked before the design review · deep blocks uninterrupted ≥80%.

**Review checkpoint:** End-of-day, 5:00 — top-3 done? win? friction? carry-overs (do/move/drop)? energy /5?

**Manual fallback:** This is Manual Mode. With Calendar/Tasks MCP authorized, steps 1's pastes are replaced by availability windows + open-task list (read-only, times/titles only).
